# Qiskit Fall Fest 2026 — Knapsack Optimization

## Phase 2 Project

This repository contains our Phase 2 work for the Qiskit Fall Fest optimization challenge.

### Objectives
- Design and evaluate custom Processor D.
- Perform Bell-state experiments.
- Solve the Knapsack optimization problem using QAOA.
- Compare ideal and noisy simulation results.
- Document findings, figures, and benchmarks.

### Tools
- Python
- Qiskit
- Qiskit Aer
- Google Colab
